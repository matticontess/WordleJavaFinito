Detailed Description

Authors
mattia.contessa & simone.ceniccola

Classe che si occupa di gestire i file di testo e binari, in particolare si occupa di leggere le parole e metterle in un ArrayList, di gestire le statistiche leggendole e scrivendole su un file strutturato.

ArrayList< String > guesstheword.GestoreFile.getParole ( )
static

Metodo statico che si occupa di leggere le parole da un file di testo e metterle in un ArrayList, se il file non esiste o è vuoto viene restituito un ArrayList con le parole di default. Sono gestite anche le eccezioni tramite JDialog e uscite dal programma con corrispettivo codice.

Returns
ArrayList<String> con le parole lette o di default

Metodo statico che si occupa di leggere le statistiche da un file binario, se non esiste viene restituito un oggetto Statistiche con valori di default. Ogni errore viene gestito tramite JDialog e uscita dal programma con corrispettivo codice.

Returns
Statistiche lette dal file o di default
